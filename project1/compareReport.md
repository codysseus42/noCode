## 자동화 도구 구현(Make vs n8n) 과정 요약

워크플로우:

Google Form제출->구글 스프레드 시트에 응답기록(구글 폼 자체기능) ->Trigger Cron 식으로 매 정각부터 15분 주기로 자공(0,15,30,45 다음 정각)-> 제미나이 연동 주관식 체점 기존점수에 주관식 점수를 더 함(교사에게 보내는 편지 체점 0 or 1)->제미나이 주관식 내용에 코멘트(교사의 답장)  보너스1 ->  점수에 따라 분기(Trigger1)-> google sheets 기록-> 합격/불합격 답장이 포함된 gmail 전송

```mermaid
graph TD
    A[Google Form제출] --> B[구글 스프레드 시트에 응답기록(구글 폼 자체기능)]--> C [Trigger Cron 식으로 매 정각부터 15분 주기로 자공(0,15,30,45 다음 정각)]--> D [제미나이 연동 주관식 체점 기존점수에 주관식 점수를 더 함(교사에게 보내는 편지 체점 0 or 1)]-> E [제미나이 주관식 내용에 코멘트(교사의 답장)  보너스1] --> E{점수에 따라 분기 3점 이상 미만}
    E-->|3 점이상| F[구글 스프레드시트 record 파일 pass 시트에 점수와 답변내용 이메일주소, 제출시간,현재시간,isNew Column y로 기록] -> G[pass sheet에서 isNew  값이 y인 줄들만 읽어들임 후에 메일 전송시 사용] -->H[스프레드 시트에서 G에서 읽어들인 행번호의 isNew 값 N 으로 업데이트]--> I[F에서 읽어들인 값들로 메일전송] 
    E-->K3 점 미만| F[구글 스프레드시트 record 파일 pass 시트에 점수와 답변내용 이메일주소, 제출시간,현재시간,isNew Column y로 기록] -> L[pass sheet에서 isNew  값이 y인 줄들만 읽어들임 후에 메일 전송시 사용] -->M[스프레드 시트에서 G에서 읽어들인 행번호의 isNew 값 N 으로 업데이트]--> I[F에서 읽어들인 값들로 메일전송]
    ```
